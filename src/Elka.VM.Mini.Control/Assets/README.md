# Application icon

`ElkaMiniControl.png` is the original generated artwork. `ElkaMiniControl.ico`
contains transparent 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel frames for
Windows Explorer, the window title bar and the system tray.

Generated using the built-in image-generation tool, with the owner's existing
Elka VoiceMeeter FX Host icon as a style reference. No API key or image-generation
service is used by the application. Rebuild the ICO with `tools/BuildIcon.ps1`
from the repository root (Windows PowerShell).

Generation prompt:

> Use case: logo-brand. Generate one finished Windows application icon for Elka VM Mini Control, an audio submix control app. The attached image is a STYLE REFERENCE ONLY from another Elka app: dark charcoal rounded-square beveled tile, thin steel-blue edge, luminous teal audio lines with a warm orange selected element. Create a fresh submixing concept: three very bold simplified vertical mixer faders in cyan/teal, with the middle selected fader cap warm orange, and a restrained branching/merging signal motif at the bottom indicating submix buses. Premium softly beveled 3D instrument-control appearance matching the reference. Frontal orthographic square composition, not a perspective mockup. Crisp strong silhouette, large readable controls, generous thick strokes legible at 16px/32px tray sizes. Palette charcoal #111417 and #222A30, teal #22A6B3 with luminous cyan highlights, orange #F08A3E for selected fader. No lettering, words, numbers, logos, hands, extra UI, or thin decorative details. One single icon filling about 94 percent of a square canvas, fully transparent outside the rounded-square tile, preserve alpha. The reference's exact diagram must not be reused; create the submix/fader symbol described.
